Privacy Policy

Last updated September 17, 2026. This page describes the AetherTab Chrome extension published at the Chrome Web Store and documented at github.com/yiyuanlee/AetherTab.

What AetherTab stores on your device

Collections (saved pages and their titles/URLs), theme preference, weather unit, weather location, and a short-lived weather cache are written with chrome.storage.local. In the local preview file they fall back to localStorage. That data does not go to an AetherTab server. There is no AetherTab account.

Permissions

  • tabs lists open tabs so you can save, drag, and close them. AetherTab reads tab titles and URLs for that purpose.
  • storage keeps collections and settings on this browser.
  • favicon loads site icons through Chrome's favicon API.
  • geolocation is optional. It is used only if you press GPS on the weather card. You can type a city name instead.

Network requests we do not control

Weather forecasts are requested from Open-Meteo (api.open-meteo.com and geocoding-api.open-meteo.com). If you use GPS, AetherTab asks BigDataCloud to turn coordinates into a place name. Those operators receive the request your browser sends (coordinates or city query, plus ordinary HTTP metadata). AetherTab does not send your collections to them.

The unpackaged HTML preview may load favicons from Google's public favicon service. The installed extension uses Chrome's own favicon API instead.

What we do not do

AetherTab does not include analytics, ads, or account signup. It does not sell data. It does not upload saved collections to a developer-operated backend because this project does not run one.

This website

The marketing pages at aethertab.com are static files. They do not set an analytics cookie. Chrome Web Store and GitHub are separate services with their own policies if you leave this site to install the extension or view source.

Contact

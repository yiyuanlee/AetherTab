Comparison

A Toby-style workspace that does not need a login

Toby popularized collections of tabs on a new tab page. AetherTab copies that job with a narrower contract: the dashboard is local, open source, and does not ask you to create an AetherTab account.

This page only lists differences you can check in the installed extension and the public repository. It is not a review of Toby's current paid plans.

AetherTab
Account None. There is no signup screen.
Where collections live chrome.storage.local on this browser. Uninstalling the extension removes that data unless you export it yourself.
Surface Replaces the new tab page. Open tabs stay in a sidebar on that same page.
Save and close Drag a live tab onto a collection. The page is saved, then Chrome closes that tab.
Source MIT licensed at github.com/yiyuanlee/AetherTab.

What you give up

Because collections stay on the device, a second computer does not see them unless Chrome syncs that storage through your Google account, or you copy data by hand. AetherTab is the wrong tool if you need a hosted team workspace.

What the dashboard adds on top of a list

Domain grouping folds same-site pages into folders on a card. Card search filters one collection. The header has a clock and an optional weather card. Light and dark themes are a single toggle.

Install from the Chrome Web Store. Read the privacy policy before you grant location access for weather.

Chrome tab manager

A tab manager that lives on your new tab page

Save open Chrome tabs into collections, close them, and reopen them from a glassmorphic dashboard. Everything stays on your machine. No account.

Add to Chrome View source

The new tab page is the workspace. Open tabs sit on the left. Collections sit on the right.

Built for a messy tab strip

Drag, save, close

Drop an open tab onto a collection. AetherTab stores the page and closes the tab so the window thins out immediately.

Group by site

Same-domain pages fold into collapsible folders, such as three Google Docs sitting in one stack instead of a long list.

Search inside a collection

Filter one card without scanning the rest of the dashboard. Useful when a research pile has grown.

Local by default

Collections, theme, and weather settings use Chrome storage on this browser. There is no AetherTab login.

How a session gets cleared

  1. 1. Park the live tabsThe sidebar lists what is open right now. Drag one tab, or save the whole window as a session.
  2. 2. File it in a collectionWork, reading, a single project. Domain grouping and the card search sit on the collection itself.
  3. 3. Open it later from the new tab pageClick a saved page, or restore a whole collection, without hunting through the tab strip.

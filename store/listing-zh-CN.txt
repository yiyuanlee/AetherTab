详细说明 — 从下方开始粘贴

AetherTab 将 Chrome 新标签页变成直观的标签页与书签工作区。将打开的网页保存到收藏夹，导入已有书签，随时回到项目，不必一直把所有标签开着。

保存标签与会话
从侧边栏将标签拖入收藏夹，保存网页后自动关闭原标签。使用 Save Session 保存当前窗口，需要时再打开已保存的网页。

导入已有书签
直接导入 Chrome 书签，或选择浏览器 HTML、Toby JSON/TXT 导出文件及 AetherTab 分享文件。保存前可预览导入内容。支持新旧 Toby 导出结构；不导入 Toby 笔记和标签。

整理收藏夹
为研究、阅读和不同项目建立收藏夹。在收藏夹内搜索、调整链接顺序，或按网站分组。书签分类与重复链接检测在当前设备本地完成。

分享有用的链接
将收藏夹导出为分享码或 JSON 文件。接收端支持时，也可通过直达链接进入导入流程。分享内容包含收藏夹名称、链接标题和网址。

定制新标签页
四套配色均支持亮色与暗色模式。提供键盘快捷键、删除撤销，以及可选的天气组件，支持城市搜索或定位。

本地存储，可选同步
无需单独注册 AetherTab 账号。收藏夹与偏好保存在 Chrome 存储中。可开启 Chrome Sync，在登录同一 Chrome 账号的浏览器间同步收藏夹。

隐私与权限
标签页权限用于列出、保存和关闭标签；书签权限用于直接导入 Chrome 书签；存储权限用于保存收藏夹和偏好。定位为可选功能，仅用于基于位置的天气查询。天气数据来自 Open-Meteo，可选的位置名称查询使用 BigDataCloud，网站图标使用 Chrome favicon API。AetherTab 不会将收藏夹发送到自己的服务器。启用 Chrome Sync 或主动分享收藏夹时，相应数据会用于同步或分享。

DETAILED DESCRIPTION — paste the text below

AetherTab turns your Chrome new tab page into a visual workspace for tabs and bookmarks. Save open tabs into collections, import your existing bookmarks, and return to a project without keeping every page open.

SAVE TABS AND SESSIONS
Drag a tab from the sidebar into a collection to save the page and close the original tab. Use Save Session to save the current window, then reopen saved pages when you need them.

BRING YOUR BOOKMARKS
Import Chrome bookmarks directly, or import browser HTML exports, Toby JSON/TXT exports, and AetherTab share files. Preview the import before saving. Both legacy and newer Toby export layouts are supported; Toby notes and tags are not imported.

ORGANIZE YOUR COLLECTIONS
Keep research, reading lists, and projects in separate collections. Search within a collection, reorder saved links, or group pages by website. Bookmark categorization and duplicate detection run locally on your device.

SHARE USEFUL LINKS
Share a collection as a portable code or JSON file. Direct import links are also available where the receiving AetherTab installation supports them. Shared collections include their name, link titles, and URLs.

MAKE YOUR NEW TAB YOUR OWN
Choose from four accent themes with light and dark modes. Use keyboard shortcuts, undo delete, and an optional weather widget with city search or location access.

LOCAL STORAGE, OPTIONAL SYNC
No separate AetherTab account is required. Collections and preferences are stored in Chrome storage. Enable optional Chrome Sync to use collections across browsers signed in to the same Chrome account.

PRIVACY AND PERMISSIONS
AetherTab uses tabs access to list, save, and close tabs, bookmarks access for direct Chrome bookmark imports, and storage for collections and preferences. Location access is optional and used for location-based weather. Weather requests go to Open-Meteo; optional location lookup uses BigDataCloud. Website icons use Chrome's favicon API. AetherTab does not send your collections to its own servers. Optional Chrome Sync and explicit collection sharing transfer data when you enable or use them.

--------------------------------------------------
Option A. Cloudflare Registrar + Cloudflare Pages (preferred)
--------------------------------------------------
1. Create a Cloudflare account and register the domain at cost.
2. In the repo, docs/ is already the site root (see wrangler.toml).
3. Cloudflare Dashboard → Workers & Pages → Create → Pages → Connect GitHub → yiyuanlee/AetherTab.
   Build command: (leave empty)
   Output directory: docs
4. Custom domains → add apex and www.
5. Redirect www → apex (or the reverse). Keep one canonical host.
6. SSL/TLS stays on Full (strict). Cloudflare issues the certificate.

DNS if you point Pages yourself:
  CNAME  @    <project>.pages.dev   (Cloudflare flattens apex)
  CNAME  www  <project>.pages.dev

--------------------------------------------------
Option B. GitHub Pages
--------------------------------------------------
1. GitHub repo Settings → Pages → Deploy from a branch → main → /docs.
2. Custom domain: aethertab.com (must match docs/CNAME).
3. Enable Enforce HTTPS after the certificate appears.

--------------------------------------------------
Google Search Console
--------------------------------------------------
1. Add a Domain property for aethertab.com (or .com).
2. Put the TXT record Cloudflare / GitHub shows you at the apex.
3. Submit https://aethertab.com/sitemap.xml
4. In Chrome Web Store Dashboard, add this domain as Homepage, Privacy policy, and Official URL.

--------------------------------------------------
Option A. Cloudflare Registrar + Workers (current)
--------------------------------------------------
1. Create a Cloudflare account and register the domain at cost.
2. Deploy from this repo: npm run deploy:site (wrangler.jsonc, assets in docs/).
3. Workers & Pages → aethertab → Settings → Domains:
   - aethertab.com (apex)
   - www.aethertab.com
   Cloudflare will create the www CNAME. site-worker.js 301s www → apex
   and *.html → the pretty URL.
4. SSL/TLS stays on Full (strict). Cloudflare issues the certificate.

Do not leave www pointing at a different host. Apex is canonical.

--------------------------------------------------
Google Search Console (domain property)
--------------------------------------------------
Use a Domain property, not a URL-prefix property. That covers
https://aethertab.com and https://www.aethertab.com together.

1. https://search.google.com/search-console → Add property → Domain → aethertab.com
2. Copy the TXT record. Cloudflare DNS → Add TXT on @ (root) → Save.
3. Click Verify in Search Console.
4. Sitemaps → add https://aethertab.com/sitemap.xml → Submit.
5. URL inspection → https://aethertab.com/ → Request indexing.
   Then request /privacy, /save-chrome-tabs, /toby-alternative.
6. Chrome Web Store Dashboard: Homepage, Privacy policy, and Official URL
   must match the canonical paths in store/listing-en.txt.
